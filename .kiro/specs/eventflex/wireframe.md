# EventFlex — Wireframe Documentation

## Overview

This document provides ASCII-based wireframes for all major screens in the EventFlex platform, organized by user role (Student, Admin, Principal) and authentication flows.

**Platform:** Web Application (Responsive Design)  
**Roles:** Student, Admin, Principal  
**Tech Stack:** React + Tailwind CSS + React Router v6
